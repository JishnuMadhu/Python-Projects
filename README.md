# Python Projects

This repository contains my Python coursework projects.

## Projects

### 1. Tic-Tac-Toe (`Tic-Tac-Toe/`)
A 2-player console Tic-Tac-Toe game in Python.
- Features: symbol selection (X/O), input validation, win/draw detection, rematch option.
- How to run:
  ```bash
  cd Tic-Tac-Toe
  python tictactoe.py
  ```

### 2. Shopping Management System (`Shopping-DBMS/`)
A console-based shopping management application using SQLite.
- Features: user registration and login, admin management (products, categories, order status), customer shopping and order history.
- How to run:
  ```bash
  cd Shopping-DBMS
  python main.py
  ```

### 3. Legends of the Forgotten Realm (`Legends-of-the-Forgotten-Realm/`)
A turn-based console RPG game.
- Features: 4 character classes, level progression (1-100), 25 enemies, 10 bosses, weapons and armor rarity, potions, skills, shop, inventory, and save/load system.
- How to run:
  ```bash
  cd Legends-of-the-Forgotten-Realm
  python main.py
  ```
